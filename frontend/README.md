# Frontend

Interfaz web de la aplicación Escuela, construida con JavaScript, Vite y pnpm.

## Estructura

```text
frontend/
├── src/
│   ├── main.js         # Punto de entrada y conexión con la API
│   └── style.css       # Estilos iniciales
├── index.html          # Documento HTML principal
├── .gitignore
├── package.json        # Dependencias y scripts del frontend
└── README.md
```

## Comandos

```bash
pnpm install
pnpm dev       # Servidor de desarrollo
pnpm build     # Compilación para producción
pnpm preview   # Previsualización de la compilación
```

Vite mostrará la dirección local en la terminal, normalmente `http://localhost:5173`.
